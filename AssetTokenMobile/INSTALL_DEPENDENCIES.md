# 📦 Install Required Dependencies

Run these commands in the AssetTokenMobile directory:

## Core Dependencies
```bash
npm install ethers@^6.13.4
npm install @walletconnect/react-native-compat
npm install @walletconnect/modal-react-native
npm install @react-native-async-storage/async-storage
npm install zustand
npm install axios
npm install react-native-svg
npm install lottie-react-native
npm install expo-secure-store
npm install expo-clipboard
npm install react-native-toast-message
npm install react-native-modal
```

## Run the installation
```bash
cd AssetTokenMobile
npx expo install ethers@^6.13.4 @walletconnect/react-native-compat @walletconnect/modal-react-native @react-native-async-storage/async-storage zustand axios react-native-svg lottie-react-native expo-secure-store expo-clipboard react-native-toast-message react-native-modal
```

After installation, continue to the next step.
